# check-chat

A simple AI Chat App for exploring the development of LLM-based Chat Apps.

## Uses

* Next.js (Full-Stack Framework)
* Clerk (Authentication)
* Convex (Database, ORM, Ratelimiting)
* Gemini (LLM API)
* Zustand (State Management)
* Tailwind (CSS Framework)
* React Markdown & Plugins (Markdown Rendering)

## Running

```bash
git clone https://github.com/Swastik2442/check-chat.git
cd check-chat
pnpm install
```

Setup the Services and set the Environment Variables similar to those in `.env.example`.

Lastly, start the server using `pnpm dev` and visit [`localhost:3000`](http://localhost:3000).
